동료 요청

검색 전용 프로그램을 쓰는 동료가 없는 자료를 검색하면 요청이 여기로 들어옵니다. 받기를 누르면 기간·세부품명이 저절로 채워져 빠진 날짜만 받고, 자동 배포가 몇 분 안에 동료 화면에 넣어 줍니다.

데이터 수집

세부품명(MAS·일반단가·제3자단가는 품명)을 넣어야 수집합니다. 이미 받아 둔 날짜는 건너뛰고 빠진 날짜만 API 로 받습니다. 기간을 31일 이하로 잘라 마지막 페이지까지 받아옵니다. 개발계정은 하루 1,000회 한도입니다.

파일 가져오기 (거래내역 · 쇼핑몰 등록품목)

나라장터에서 내려받은 파일(.csv, .xlsx)을 이 칸에 끌어다 놓거나 파일 선택을 누르세요. 납품요구 물품 내역·쇼핑몰 품목 등록 내역 모두 되고, 어느 파일인지는 저절로 알아봅니다. API 호출은 쓰지 않습니다.

OneDrive 폴더의 파일은 브라우저가 올리지 못할 때가 있습니다. 그럴 땐 경로를 붙여넣어 가져오세요 (탐색기 주소창에서 복사).

최근 수집 이력

거래내역 검색 (납품요구 상세)

수요기관이 쇼핑몰에서 사 간 물품을 한 줄씩 보거나, 아래 보기에서 월별·기관별·업체별 등으로 묶어 합계와 비중을 봅니다.

쇼핑몰 등록품목 검색

쇼핑몰에 올라와 있는 품목과 계약단가입니다. 검색을 누르면 그 세부품명의 쇼핑몰 등록품목(최근 2년 등록분)을 아직 받지 않았거나 받은 지 30일이 지난 경우 API 로 받아 채웁니다.
세부품명 없이 계약업체만 넣어도 검색합니다. 이때는 저장된 등록품목에서만 찾습니다.

계약 내역 검색 (공사·용역·물품 · 수의계약·경쟁 모두)

나라장터에 등록된 모든 계약을 찾습니다. 조달청 계약정보를 최근 1년치 받아 두고, 3시간마다 새로 등록된 계약을 이어 받습니다. 변경계약은 마지막 차수 하나만 보여 줍니다.

업체 계약 실적 i 받아 둔 계약 내역(최근 1년)으로 업체 한 곳의 계약 실적을 정리합니다.
건수·금액은 그 업체가 주계약업체로 맺은 계약만 셉니다. 공동도급 구성원으로만 들어간 계약은 지분을 몰라 따로 건수만 보여 줍니다.
업체명으로 찾아 여러 곳이 나오면 고르면 됩니다. 사업자번호로 찾으면 바로 엽니다.
이 화면은 API 를 부르지 않습니다.

물품비교 i 관심목록 탭에서 비교할 물품을 체크하고 비교하기 를 누르면 여기서 나란히 비교합니다 (최대 8개).
물품 위의 빼기 는 비교에서만 뺍니다. 관심목록에는 그대로 남습니다.
계약단가가 가장 낮은 물품에 최저 를 붙이고, 나머지는 최저보다 몇 % 비싼지 보여 줍니다.
실거래는 저장된 거래내역에서 같은 물품식별번호·같은 업체의 거래만 셉니다.
모든 물품이 같은 값인 줄은 흐리게, 모두 비어 있는 줄은 빼고 보여 줍니다.
이 화면은 API 를 부르지 않습니다.

업체 실적 i 업체를 검색해 추가하면 저장된 거래내역으로 실적을 집계합니다.
추가한 업체가 쇼핑몰에 등록한 세부품명의 거래내역 가운데 고른 기간에 아직 안 받은 날짜는 조달청에서 받아 채웁니다 (자동 받기가 켜져 있으면 일수와 상관없이 오늘 남은 한도 안에서 바로).
여러 곳을 추가하면 나란히 비교합니다 (최대 10곳).
업체 없이 세부품명·업체소재지·기관지역 조건만 넣으면 조건에 맞는 상위 업체를 보여줍니다 (전체를 고르면 납품 실적이 없는 쇼핑몰 등록업체까지).
업체를 추가했으면 그 업체들의 실적을 조건으로 좁혀 봅니다.
등록품목이 저장되지 않은 업체는 조달청에서 가져오기(동료 PC 는 관리자에게 가져오기 요청)로 등록품목을 먼저 받습니다.
그 밖의 검색·집계는 API 를 부르지 않습니다.

관심목록

등록품목·거래내역 검색 결과에서 ★ 를 누른 물품이 세부품명별로 모입니다. 단가는 지금 계약단가이고, 메모를 적어 둘 수 있습니다.

동료 배포 (검색 전용 프로그램)

자료는 이 PC 만 받고, 동료 PC 는 이 PC 가 배포한 자료로 검색만 합니다. 동료 PC 는 서비스키·OneDrive 로그인이 필요 없고, 이 PC 가 꺼져 있어도 검색됩니다. 자동 배포를 켜 두면 이 PC 가 새 자료를 받을 때마다 몇 분 안에 바뀐 줄만 배포 폴더에 올라가고, 동료 PC 가 알아서 받아 합칩니다. 서비스키·설정·관심목록·API 사용량은 배포하지 않습니다.

배포 폴더:
동료 PC 에 설치하는 방법
  1. 위 자동 배포를 켜서 기본자료를 한 번 만듭니다 (처음엔 몇십 초 걸립니다).
  2. 파일 탐색기에서 배포 폴더를 오른쪽 클릭 → 공유 → 링크 설정을 "링크가 있는 모든 사용자"·보기 가능으로 하고 링크 복사.
  3. 복사한 링크를 아래에 붙여넣고 동료용 프로그램 만들기를 누르면 배포 폴더에 G2B Finder 검색용.zip 이 생깁니다.
  4. 동료는 같은 링크를 브라우저로 열어 zip 을 받고, 원하는 곳(예: 문서 폴더)에 압축을 푼 뒤 G2B Finder 검색용.vbs 를 더블클릭합니다. 처음엔 자료를 받느라 1~3분 걸립니다.

동료 요청 받기 (동료가 없는 자료를 요청하는 곳)

동료 PC 는 조달청 API 를 부르지 않아서, 배포되지 않은 기간은 비어 있습니다. 이걸 켜 두면 동료가 그 화면에서 요청 보내기를 눌러 이 PC 에 알릴 수 있습니다. 오가는 것은 요청 쪽지(1KB 미만) 뿐이고, 요청은 현황 · 수집 화면에 쌓입니다.

요청 받기를 켜는 방법
  1. 파일 탐색기에서 배포 폴더를 오른쪽 클릭 → 공유 → 링크 설정을 "링크가 있는 모든 사용자"로 하고 편집 가능에 체크한 뒤 링크 복사.
  2. OneDrive 는 편집 가능으로 바꿀 때 주소가 다른 새 링크를 만들기도 합니다. 그럴 땐 새 링크를 위 배포 폴더 공유 링크 칸에 넣고 동료용 프로그램 만들기를 다시 누르세요. 이미 설치한 동료는 예전 링크로 자료를 계속 받으니 다시 깔 필요가 없습니다 — 예전 링크를 지우지만 마세요.
  3. 연결 시험을 누르면 동료가 하는 것과 똑같이 쪽지를 한 장 올려 보고 되는지 알려 줍니다.

링크가 편집 가능이면, 링크를 아는 사람이 배포 폴더의 파일을 지우거나 바꿀 수도 있습니다. 다만 배포 파일은 모두 이 PC 의 data/app.db 에서 다시 만들 수 있고, 파일이 바뀌면 동료 프로그램이 검사값으로 걸러 내니 망가져도 지금 배포를 한 번 누르면 됩니다. 그래도 걱정되면 아래 따로 두기를 쓰세요.

요청함 폴더:

서비스키

공공데이터포털 조달청_나라장터쇼핑몰 품목정보 서비스 에서 활용신청(자동승인)한 뒤, 마이페이지의 일반 인증키(Decoding) 를 붙여넣으세요. .env 의 G2B_SERVICE_KEY 로 넣어도 됩니다(그쪽이 우선).

내 회사

여기에 적은 업체가 "내 회사만" 필터의 기준이 되고, 업체 실적 탭에서 "내 회사 불러오기"로 한 번에 추가됩니다. 법인이 여러 개면 여러 줄로 넣으세요.

세부품명 자동완성 목록

조달청_물품목록정보서비스 에서 세부품명·품명 전체 목록을 받아 두고, 세부품명·품명 칸에 글자를 치면 후보를 보여줍니다 (초성·번호로도 찾기). 30일마다 앱이 뒤에서 새로 받습니다 (약 36회 호출).

업체 소재지 채우기

조달청_나라장터 사용자정보 서비스 로 소재지를 모르는 업체의 본사 소재지를 받아 거래내역·등록품목의 업체소재지에 씁니다. 계약 내역 탭이 나라장터 조달업체 전체의 주소를 받아 두는데, 그것을 다 받은 뒤에는 API 를 부르지 않고 그 주소로 바로 채웁니다. 그 전에는 업체 한 곳에 1회 호출이라, 거래 금액이 큰 업체부터 사용자정보 서비스 한도에서 500회를 남기고(조달업체 주소 받기 몫) 한 번에 최대 400곳씩 채웁니다. 서버가 켜질 때, 수집·가져오기가 끝날 때, 3시간마다 뒤에서 이어서 합니다. 모르는 업체를 다 채우면, 파일에서 온 계약 당시 지역 이름(전라북도·강원도 등)도 지금 이름으로 맞춥니다.

검색할 때 빠진 날짜 자동으로 받기

거래내역에서 검색 을 누르면, 그 기간 가운데 아직 저장되지 않은 날짜만 API 로 받아 채운 뒤 결과를 보여줍니다. 이미 받은 날짜는 API 를 부르지 않습니다. 빠진 날짜가 아래 일수보다 많거나 예상 호출 수가 오늘 남은 한도를 넘으면, 자동으로 받지 않고 버튼으로 물어봅니다.
